使用帮助

🔍 搜索

直接输入关键词；或点右侧“高级”按钮，点选 发件人 / 主题 / 日期 / 含附件 等条件；也支持操作符 from: subject: has:attachment before: after:。点 🔖 可把搜索保存为侧栏“智能视图”。

✅ 批量操作

勾选邮件左侧复选框 → 顶部出现批量栏：全选 / 标记已读 / 未读 / 加星 / 分类为… / 删除。

⚙️ 邮件规则

侧栏“邮件规则”进入：设定条件（发件人/主题/正文… 支持 且/或）+ 可选 AI 语义判断 → 命中后执行 分类 / 星标 / 已读 / 跳过AI / 专用摘要与回复提示词。可用自然语言一键生成规则，或让 AI 评估规则。命中的规则会在新邮件到达时自动执行（如“按发件人自动分类”）。

✨ AI 能力

邮件详情自动生成结构化摘要（含历史提醒）；“AI待办”按钮从邮件提取待办；AI 助手可就邮件多轮问答；起草回复自动匹配原文语言并附签名。

⌨️ 快捷键

↑/↓ 或 j/k 上下切换邮件（选中即打开）· Enter 打开 · / 聚焦搜索 · Cmd/Ctrl+K 命令面板 · R 回复 · A 回复全部 · S 星标 · U 切换已读 · E 删除 · C 写新邮件 · I 收件箱 · Esc 关闭弹窗
